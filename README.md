# Q-1 Gridworld

一个单文件的强化学习互动游乐场：表格型 Q-learning / SARSA 智能体在 17×11 的网格里走迷宫，界面做成极简工业风的硬件面板。直接用浏览器打开 `index.html` 即可，不需要构建步骤，也没有依赖（只从 Google Fonts 加载字体）。

## 能做什么

- **推子实时生效**：α 学习率、γ 折扣、ε 探索率、slip 侧滑概率、每步奖励 r、模拟速度（2 ~ 20k 步/秒）。
- **两种算法**：Q-learning（离策略）与 SARSA（同策略）一键切换，TD 更新公式会带着最近一步的真实数值显示出来。
- **三种视图**：V(s) 价值热力图、每个动作的 Q 值四分格、访问次数；叠加策略箭头和贪婪路线（蓝线）。
- **可编辑的世界**：画墙、熔岩、出口，移动起点；训练中途改地图，智能体在原 Q 表上重新适应。
- **地图**：Maze（随机迷宫，再按一次换一座）、Cliff（经典悬崖行走）、Rooms（四房间）、Open。
- **学习曲线**：每局步数（对数坐标）、几何滑动平均，以及到达 / 掉落 / 超时的结果色带。
- **四个预设实验**：悬崖上的 Q-learning vs SARSA、过高的每步代价让智能体选择跳崖、高 ε 下的离策略学习、有风世界里的 α。

## 快捷键

`Space` 运行 / 暂停 · `S` 单步 · `F` 立即训练 200 局 · `C` 清空 Q 表
